首页 / Mock 测试入口
🧪 Mock 环境 — 这是一个本地静态靶场, 模拟 AiTest / PingCode 的关键 DOM 结构。 用于在无内网权限时开发 / 测试 TestMateX 浏览器插件。

入口说明

1. 项目列表页 (library)
/Dml/AiTest/index/automationManage-library — 模拟 ant-table 项目 / 任务表
2. 任务详情页 (taskDetail)
/Dml/AiTest/index/automationManage-taskDetail?taskId=9999 — 模拟单个任务 + 失败用例
3. PingCode 登录页
/pingcode.html — 模拟 PingCode 已登录态 (提供 JWT 接口)
4. ENV 模式
默认 mock — 数据由 js/config.js 控制, 切 prod 即走真实抓取

使用流程

步骤 1
打开 任务详情页
步骤 2
点击右下角浮动按钮 🚀 自动化分析与提单
步骤 3
侧边栏弹出, 选择失败用例, 点击 [提交到 PingCode]
步骤 4
弹窗显示 S3100V1R1-NNNN 伪工单号 (mock 模式) 或真实工单 (prod 模式)
